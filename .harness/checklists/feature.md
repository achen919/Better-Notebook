# Feature Checklist

适用于普通页面、组件、store、工具函数和非底层能力变更。

## 开发前

- [ ] 已明确任务目标和非目标
- [ ] 已确认影响范围和关联页面
- [ ] 已确认是否需要改动 store、路由或共享类型
- [ ] 已确认是否涉及 Electron IPC 或数据库；如果涉及，追加检查 `ipc-db.md`

## 开发中

- [ ] 新增逻辑放在合适层级，避免页面组件承担过多业务逻辑
- [ ] 复用现有类型、工具函数和 store，而不是重复实现
- [ ] 对用户可见文案保持一致
- [ ] 对空状态、加载态、报错态有基本处理
- [ ] 不引入明显的状态同步问题或重复请求

## 提交前

- [ ] 执行 `yarn lint`
- [ ] 执行 `yarn build:web`
- [ ] 检查主要用户路径至少 1 次
- [ ] 记录仍未覆盖的风险点
